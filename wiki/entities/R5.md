R5 is the routing engine used by r5py, according to the Helsinki Region Travel Time Matrix 2023 page. The Digital Geography Lab describes using a locally patched R5 fork to account for Helsinki-specific characteristics and local data.

## Key Points

- The source describes R5 as the engine used through r5py for matrix calculations.
- A patched fork and a companion repository handle local modifications and matrix processing.
- The source does not establish that Aluevaaka needs to run R5 itself to use the published matrix.
